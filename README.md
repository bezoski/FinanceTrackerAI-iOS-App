# FinanceTracker AI 💸

A modern, native iOS application designed to help users track their daily finances effortlessly. The app provides beautiful visual summaries, multi-currency support, and AI-driven insights to help users better understand their spending habits and maintain a healthy budget.

## 🛠 Built With

* **SwiftUI** – Declarative UI framework
* **SwiftData** – Fast and reliable on-device persistence
* **Swift Charts** – Native data visualization
* **CoreML** – Prepared for on-device machine learning insights

## ⚙️ System Requirements

* **OS:** iOS 17.0+ (required for SwiftData)
* **IDE:** Xcode 15.0+
* **Language:** Swift 5.9+

## 🚀 Getting Started

1. Clone or download this repository to your local machine.
2. Open `FinanceTrackerAI.xcodeproj` in Xcode.
3. Select an iOS 17.0+ Simulator or a physical device.
4. Press `Cmd + R` to build and run the app.
